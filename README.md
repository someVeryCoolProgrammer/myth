# About

Myth os is a privacy respecting, easy to use os. This os is currently under-developement and will probably be for some time. Most code in this codebase currently is taken form: https://www.youtube.com/watch?v=9t-SPC7Tczc&list=PLFjM7v6KGMpiH2G-kT781ByCNC_0pKpPN&index=1. This won't be the case forever.

# Getting started 

```shell
git clone https://github.com/someVeryCoolProgrammer/myth.git

sudo apt install qemu, make

mkdir bin

make

qemu-system-x86_64 -fda bin/main_floppy.img -boot a
```
