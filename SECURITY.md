# Reporting A Vulnerability

If you discover a vulnerability, please report it through:
- [GitHub's private vulnerability reporting](https://github.com/someVeryCoolProgrammer/outshell/security/advisories/new)

Other methods of reporting are NOT supported. 
  
Please include:
- A description of the vulnerability
- Steps to reproduce it
- Any relevant screenshots, videos, and/or other relevant information
- myth version
