# outshell's Coding Standards

- Use 4 spaces.
- Document all functions, somewhat like google style docstrings in python.
- Avoid nesting should be avoided as much as possible.
- Try **NOT** to collect any user data where possible.
- All .md files should be all upder-case. Eg: EXAMPLE_ONE.md. 
- Use snake case for multi-word names. Eg: char [100]some_string = "My string.";

# Pull Requests

1) Fork or clone the myth's repository
2) Create a branch for your changes
3) Open a pull request explaining:  
    - What did you change?  
    - Why you changed what you changed?  
    - How will this improve myth?
